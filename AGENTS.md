# Agent Instructions

1. Treat evidence as authoritative only when a traceable source reference exists.
2. Never invent metrics, testimonials, timelines, screenshots, or results.
3. Do not change `claim_status` to `verified` without evidence.
4. Do not generate publishable assets from draft, rejected, or needs-review proof.
5. Keep real client data and proprietary operating methods out of this public repository.
6. Preserve source references in generated working material.
7. Do not imply causation when evidence only supports correlation.
8. Do not state or imply guaranteed/typical results unless separately supported.
9. Run validation and tests after changing schemas or generation logic.
