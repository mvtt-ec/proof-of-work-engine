# Security Policy

This public repository must never contain:
- API keys, tokens, passwords, cookies, private keys, recovery codes
- real client credentials or identifying private information
- confidential client screenshots
- private analytics/CRM exports
- unpublished client financial information
- proprietary internal scoring, decision rules, sales logic, prompts, or operating methods that are not intended for public release

Use synthetic examples publicly. Store real evidence and proprietary workflows in the private proof vault.
